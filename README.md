# Zimoholdijk plugins

A catalog of my plugins and skills for AI coding tools. Each plugin lives in its own repo; this repo only lists them.

## Claude Code

```
/plugin marketplace add Zimoholdijk/plugins
```

Then install any of these:

| Plugin | What it does | Install |
|--------|--------------|---------|
| [plan-first](https://github.com/Zimoholdijk/plan-first-development) | PRD-first development workflow with testing built in | `/plugin install plan-first@zimoholdijk` |
| [collapse-diffs](https://github.com/Zimoholdijk/collapse-diffs) | Hides the diff under successful Edit and Write tool rows | `/plugin install collapse-diffs@zimoholdijk` |
| [zimo-freelance-docs](https://github.com/Zimoholdijk/zimo-freelance-docs) | Scoping documents, quotations and signable proposals from client calls and emails | `/plugin install zimo-freelance-docs@zimoholdijk` |

Other tools will get their own catalogs here as plugins for them are added.
